# 🎓 SAKHI – Smart AI Classroom & Knowledge Hub for Interaction

## 📌 Overview

**SAKHI (Smart AI Classroom & Knowledge Hub for Interaction)** is an AI-powered Smart Classroom platform developed to transform traditional classrooms into intelligent, interactive, and student-centric learning environments.

The platform integrates AI assistance, automated quiz generation, classroom management, anonymous feedback, and role-based dashboards to enhance the learning experience for **Students, Teachers, and HODs**.

---

# 🚀 Problem Statement

Traditional classrooms often face challenges such as:

* Limited personalized learning
* Delayed doubt resolution
* Manual quiz preparation
* Lack of anonymous student feedback
* Poor communication between students and faculty
* Fragmented classroom resources

SAKHI addresses these challenges by providing an all-in-one AI-powered classroom ecosystem.

---

# ✨ Key Features

## 👨‍🎓 Student Dashboard

Students can:

* Login securely
* View study materials
* Upload PDFs for learning
* Chat with AI Classroom Assistant
* Generate quizzes instantly
* Attempt quizzes
* View attendance
* Check announcements
* Submit anonymous complaints
* Access classroom resources

---

## 👩‍🏫 Teacher Dashboard

Teachers can:

* Upload notes and study material
* Upload PDF documents
* Generate quizzes automatically
* Monitor student progress
* Manage classroom resources
* View student complaints
* Make announcements
* Manage attendance

---

## 👨‍💼 HOD Dashboard

The HOD has complete administrative control.

Features include:

* Monitor teachers
* View classroom analytics
* Review anonymous complaints
* Manage announcements
* Access overall classroom statistics
* Supervise platform usage

---

# 🤖 AI Classroom Assistant

SAKHI includes an intelligent AI assistant that can:

* Answer academic questions
* Explain concepts
* Help with assignments
* Guide students
* Provide instant learning support

This reduces dependency on teachers for repetitive doubts while enabling 24×7 assistance.

---

# 📄 Smart PDF Learning

Students or teachers can upload PDF notes.

The system extracts text automatically and allows users to:

* Read extracted content
* Ask questions from uploaded notes
* Generate quizzes directly from PDFs

---

# 📝 Automatic Quiz Generator

One of SAKHI's major features is AI-based quiz generation.

Users can:

* Upload study material
* Automatically generate MCQs
* Practice instantly
* Improve revision efficiency

---

# 📮 CHITTI – Anonymous Complaint Box

Students often hesitate to report issues openly.

CHITTI allows students to submit anonymous complaints regarding:

* Ragging
* Classroom issues
* Faculty concerns
* Infrastructure problems
* Mental well-being
* Suggestions

The HOD and authorized faculty can review complaints while maintaining student anonymity.

---

# 📢 Announcements

Teachers and administrators can post important announcements such as:

* Exams
* Assignments
* Events
* Holiday notices
* Classroom updates

Students receive all updates in one place.

---

# 🔐 Role-Based Authentication

The platform supports secure login for:

* Student
* Teacher
* HOD

Each role has its own dashboard and permissions.
